## 2024-05-14 - Iterating over ranges of LocalDate is slow using `plus(1, DateTimeUnit.DAY)`
**Learning:** `LocalDate.plus(1, DateTimeUnit.DAY)` and `generateSequence(start) { it.plus(1, DateTimeUnit.DAY) }` are much slower than iterating over epoch days and converting them to `LocalDate` using `LocalDate.fromEpochDays()`. This is because `plus` performs full calendar math (handling leap years, month lengths, etc.) on every step, while converting from an epoch day is faster. In `orrery-core`, iterating over a range of dates to check for disabled dates takes ~300ms for 3 years using `plus` but only ~80ms using `fromEpochDays`.
**Action:** When iterating over a range of dates, convert the start and end dates to epoch days (`toEpochDays()`), iterate over the integer range, and convert each day back to a `LocalDate` using `LocalDate.fromEpochDays()`. This avoids creating unnecessary sequences and performing expensive calendar math. This is a very targeted performance optimization to `SelectionEngine` and `CalendarSelectionState`.
